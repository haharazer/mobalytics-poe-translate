本地译文缓存

支持 1 至 100,000 条。降低上限会立即移除超出的最早记录。展开一条记录可对照待译片段与译文。

API 请求日志

本机保留最近 100 次 API 请求。展开失败记录可查看错误阶段和服务端响应前 4,096 个字符。命中缓存不会产生 API 请求。
