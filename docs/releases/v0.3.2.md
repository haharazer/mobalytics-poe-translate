# v0.3.2 核心游戏内容翻译

本次从 0.1.0 的技能名称翻译扩展到技能说明、传奇装备、装备基底、数值词缀与天赋效果。

## 新功能

- 保留原有 812 条技能名称及 Support 省略别名。
- 接入主动技能描述、辅助宝石说明、装备/物品基底、传奇名称与天赋名称。
- 增加客户端属性显示规则，翻译可识别的装备数值词缀、技能效果和天赋专精选项，保留数值、正负号和范围。
- 新增六类独立开关，支持简体、繁体、中英双语和恢复英文。
- 支持动态提示、Build Variant 切换及 React 复用文本节点。
- 修复数字与句子拆成相邻文本节点时漏译的问题，包括专注吟唱的消耗、伤害与品质效果。
- 翻译在浏览器本地完成，扩展权限未增加。

## 安装与升级

下载 `mobalytics-poe-translate-v0.3.2.zip` 并解压，在 Chrome/Edge 扩展管理页开启开发者模式后选择「加载已解压的扩展程序」。

升级现有扩展时，可将运行时文件更新到原安装目录，再点击「重新加载」并刷新攻略页。
如果改用新的解压目录，请先关闭旧扩展，避免两个版本同时翻译；扩展卡片版本应显示 `0.3.2`。
不要只解压 ZIP 后刷新网页，浏览器仍可能使用旧扩展代码。

## 验证与边界

- 26 项单元测试和 31 项本地浏览器回归检查通过。
- 用户已在 Fubgun Winter Orb 攻略页验证本轮翻译效果。
- 安装包附 SHA-256 校验文件。
- 词条/规则数量是候选数据量，不等于所有页面内容均可翻译。
- 未识别规则、缺失语言、同名歧义及暂不支持的复杂格式继续显示英文。
- DOM 天赋效果和提示卡可处理；纯 Canvas/WebGL 文字、完整攻略机器翻译和 PoE 2 尚未覆盖。
- 客户端版本与文本修改情况保留在仓库的数据报告中，数据不宣称为同版本、未经修改的官方基线。
