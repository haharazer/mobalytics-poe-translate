# 商店图片素材

## 文件

- `icon-128.png`：扩展商店图标，`128 × 128`，RGBA PNG。
- `store-screenshot-1280x800.png`：商店产品截图，`1280 × 800`，RGB PNG。
- `store-screenshot.html`：产品截图的可维护 HTML/CSS 渲染源。

这是明确标注的产品界面示意图，不是真实攻略页截图。示例名称与属性句子来自
扩展内置 PoE 1 三语数据，展示 0.3.2 的六类开关、传奇名称、数值词缀与天赋效果。

重新导出截图时，以 `1280 × 800` 浏览器视口打开
`store-assets/store-screenshot.html`，截取当前视口即可。
